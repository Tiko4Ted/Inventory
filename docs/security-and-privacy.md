# Security and privacy checklist

- Use managed authentication in production.
- Use role-based authorization on every API route.
- Add a pharmacy or organization ID to every persistent record.
- Never expose private shelf-image URLs publicly.
- Keep AI prompts free of personally identifiable client data.
- Encrypt traffic in transit and protect database credentials.
- Store SMS consent and opt-out status.
- Keep an audit record for stock and client changes.
- Define retention and deletion policies.
- Perform a local regulatory review before handling identifiable family-planning records.
