# Family-planning roadmap

This feature follows inventory because inventory is the first operational dependency.

Planned records:

- Client identifier or clinic-issued reference
- Consent for storage and SMS reminders
- Family-planning method or service type
- Service date
- Recommended return date
- Reminder status and delivery attempts
- Opt-out state

The system should avoid storing more clinical information than is necessary to support a safe,
consented follow-up reminder.
